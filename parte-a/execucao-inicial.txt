8. ERROS ENCONTRADOS E SOLUÇÕES
=============================================================
E1: "address already in use" ao executar `ollama serve`
    → Ollama já estava rodando como daemon. Solução: usar `ollama list` para confirmar; ignorar o erro.

E2: ".venv/bin/activate: No such file or directory"
    → venv não havia sido criado. Solução: `python3 -m venv .venv` antes de ativar.

E3: Falha no pip com numpy 1.26.4, pydantic-core, pi_heif (Python 3.14)
    → Sem wheels disponíveis; build requer gcc/libheif ausentes no WSL2 mínimo.
    → Solução: instalar somente dependências essenciais com versões atuais.

E4: ImportError — UnstructuredPDFLoader (pacote `unstructured` não instalado)
    → Solução: substituir por PyPDFLoader em src/app/main.py.

E5: "nomic-embed-text:latest does not support chat" (status 400)
    → Dropdown selecionava o modelo de embedding como modelo de chat.
    → Solução: filtrar modelos com "embed" no nome antes de popular o selectbox.

E6: MultiQueryRetriever sem atributo get_relevant_documents
    → API depreciada no LangChain 1.x.
    → Solução: sed -i 's/\.get_relevant_documents(/.invoke(/g' src/app/main.py

E7: "request (4193 tokens) exceeds context size (4096)" (status 400)
    → Chunks do PDF somados ao prompt ultrapassam o limite padrão.
    → Solução: ChatOllama(model=selected_model, num_ctx=8192)
